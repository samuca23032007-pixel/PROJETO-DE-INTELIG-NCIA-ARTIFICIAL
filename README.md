# 🧠 Projeto de Inteligência Artificial

Projeto de IA em Python com duas partes: um chatbot e um modelo de previsão de score de crédito de clientes para uma empresa financeira, que alcançou 86% de acurácia.

## ✨ Funcionalidades

- 💬 Chatbot de IA criado em Python
- 📊 Modelo de inteligência artificial que prevê o score de crédito dos clientes com base em suas características
- 🎯 Acurácia de 86% nas previsões

## 🛠️ Tecnologias

- Python
- Jupyter Notebook

## 📁 Estrutura do projeto

```
├── CRIAÇÃO DE UM CHATBOT DE IA.py   # Script do chatbot
├── inicial.ipynb                    # Notebook com o modelo de IA
└── README.md
```

## ▶️ Como executar

1. Chatbot:

```bash
python "CRIAÇÃO DE UM CHATBOT DE IA.py"
```

2. Modelo de score de crédito: abra o notebook no Jupyter ou no VS Code.

```bash
jupyter notebook inicial.ipynb
```
